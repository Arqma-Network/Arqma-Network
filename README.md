## What this page is for

This is the GitHub home of Arqma Wallet, the official open-source wallet for Arqma (ARQ): a desktop GUI on Windows, macOS and Linux, command-line tools beside it, and native apps on Android and iOS. The application itself is at [Arqma-Network/Arqma-Wallet](https://github.com/Arqma-Network/Arqma-Wallet), and this page is the map to everything around it, which is five documentation repositories, the installers on the current release and the 34 guides that answer what a holder actually asks.

The software is non-custodial, holds a 25-word seed that is shown once at creation, runs with no account, no email and no telemetry, and is published by a volunteer project with no foundation, no venture backing and no token sale behind it. What this page does not do is sell anything: there is no price, no forecast and no reason to buy here, and the wallet holds ARQ alone on a single chain. The guides exist so that a person holding ARQ can finish the job in front of them without opening a support ticket, and so that a person who has lost access can find out quickly what is still possible.

## Who it is for

- You have never installed the wallet, and you want the file you run to be the file the project published.
- You hold ARQ already and a balance, a send or a sync has stopped behaving the way it did last week.
- You restored from the seed and need to know whether an empty balance is a rescan that is still running or a real loss.
- You run a node, a service node or a miner, and you want the ports, the stake and the requirements in one place.

## Common first questions

### Does the wallet need an account or a sign-up?

No. There is no account, no email and no KYC step inside the application, and no analytics SDK in the build. The 25 words are the only credential, which is why they are written down offline and typed into nothing but the wallet itself.

### Is Arqma Wallet free to use?

Yes. The software is free, with no subscription and no purchase price, so the only cost of using it is the network fee on a transfer. That fee is paid to miners and service nodes on this chain, never to a company.

### Which systems are supported?

Windows 10 and 11 on 64-bit, macOS on Intel or Apple Silicon, and Linux x86_64 take the desktop build, while Android and iOS have native apps that read the chain through a remote node. The project publishes no support statement for older systems, and this page makes no claim beyond the one the release page makes.

### Is a phone wallet safe for a real balance?

It is as safe as the phrase behind it, and a phone is the device most likely to be lost or replaced. The recovery collection explains exactly what a lost device costs when the 25 words exist on paper and what it costs when they do not.

### Where do I report a bug?

The issue tracker on the [application repository](https://github.com/Arqma-Network/Arqma-Wallet/issues) is the place, and a report that names the build, the platform and the exact step gets answered faster. No support channel will ask for a seed phrase, a password or a private key.

## Before you install

Compare the installer with the SHA-256 published on the release page before you run it, and treat any other download page as unverified regardless of how familiar it looks. The wallet is a file you execute on your own machine: that check is the only thing standing between a correct download and a convincing copy of one.

## About

Arqma Wallet is documentation-heavy on purpose, because a wallet is software that holds money and most of its questions are about what happened rather than what to click. Nothing on this page is a download link for a file that is not attached to the release page, and no guide here asks for a seed phrase, a private key or a password.
